# Bug Report / Feature Request

## Issue Type

Please check the type of issue you are filing:

- [ ] 🐛 **Bug Report** – Something isn't working as expected
- [ ] ✨ **Feature Request** – A new utility method or module
- [ ] 📖 **Documentation** – A documentation fix or improvement
- [ ] 🔧 **Refactoring** – Code quality improvement without functional change
- [ ] 🧪 **Test Gap** – A missing or insufficient test case

---

## For Bug Reports

### Description

> A clear and concise description of the bug.

### Steps to Reproduce

```
1. Call utility method X with input Y
2. Observe result Z
3. ...
```

### Expected Behaviour

> What you expected to happen.

### Actual Behaviour

> What actually happened. Include full stack traces if applicable.

```
Exception in thread "main" ...
```
